 🌱 AgroGuide – Smart Agriculture Web App

📌 Description
AgroGuide is an AI-powered web application that helps farmers with crop recommendations and farming insights.

---

🚀 Features
- AI-based crop suggestions  
- Farming guidance  
- User-friendly interface  

---

🛠️ Tech Stack
- Python  
- Streamlit  
- MySQL  

---
▶️ How to Run
pip install streamlit mysql-connector-python  
streamlit run app.py
